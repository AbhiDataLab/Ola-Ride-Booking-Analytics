 Ola Ride Booking Analytics

 Project Overview

This project analyzes Ola ride booking data using Python, SQL, and Power BI to uncover insights into customer behavior, booking trends, cancellations, revenue, and operational performance.

The project follows a complete data analytics workflow, including data cleaning, SQL analysis, dashboard creation, and business recommendations.

---

 Business Problem

Ride-sharing companies generate millions of booking records every day. Understanding booking patterns, cancellations, customer preferences, and revenue trends helps improve operational efficiency and customer satisfaction.
